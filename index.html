Multidisciplinary student project

Can a low-cost gas sensor give earlier banana ripening warnings?

We combine banana images, temperature and humidity, and a general gas-response signal on an ESP32 prototype, then test fairly whether each addition improves early ripening warnings on independent batches.

Project objective

🎯

Core question

Does adding gas-sensor readings improve early warning of banana ripening compared with images and environmental readings alone?

📚

Why it is new

Prior work covers image-based ripeness prediction, ML on ESP32 sensor data, and specialised ethylene sensors. We aim to show a measurable improvement, not just combine sensors.

💰

Affordable focus

We investigate a low-cost approach, while openly acknowledging the limits of low-cost gas sensors.

Sensor and input overview

📷

Banana images

Camera images captured under a fixed protocol show visible ripening changes such as colour and spotting.

🌡️

DHT22 — environment only

Temperature and relative humidity inside the chamber. Used only as environmental context, not as a ripeness measure.

🌫️

MQ-135 — gas-only

A general gas-response signal over time. It is not ethylene-selective; see the disclosure below.

🧠

ESP32

Collects readings, adds timestamps and sends data to a laptop for analysis. It does not decide ripeness; the software does.

Disclosure: the MQ-135 is a general-purpose air-quality sensor that responds to several gases and vapours. Its output is not ethylene concentration and cannot confirm ethylene levels. We treat it only as a general gas-response signal.

Methodology preview

Five comparisons are run on the same evaluation batches, so differences come from the inputs, not the data.

ComparisonImagesDHT22MQ-135

Baseline first

The baseline begins with a simple rule-based trend, or regression/classification, before any more complex model is considered.

Process

  1. Fix chamber, loading and image protocol, with empty-chamber controls.
  2. Pilot run to measure sensor drift and recording intervals.
  3. Collect independent batches.
  4. Quantify what gas sensing adds.
